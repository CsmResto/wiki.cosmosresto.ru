## Настройка интеграции IIKO Card с CosmosResto

Для передачи данных из IIKO Card в CosmosResto необходимо создать и настроить webhook-уведомление.

### Создание webhook

**Для настройки интеграции с IIKO Card запросите у поддержки CosmosResto следующие реквизиты:**
   - URL
   - Пароль

1. Выполните вход в IIKO Card.

2. Перейдите в раздел `Настройки -> Webhook-уведомления`.

3. Нажмите `+ Создать`.

4. Заполните следующие поля:
   1. Название — произвольное название webhook
   2. URL отправки одиночных webhook-уведомлений — адрес, предоставленный службой поддержки CosmosResto
   3. Пароль — пароль для webhook, предоставленный службой поддержки CosmosResto

5. Включите следующие события:
   1. Смена баланса пользователя
   2. Смена категории гостя
   3. Смена карты пользователя
   4. Смена участия пользователя

5. Сохраните Webhook.

[[info type=custom color=#E06823]]
Если необходимо отображать количество бонусов на электронной карте гостя, сообщите в поддержку CosmosResto **название основной бонусной программы из IIKO Card**. В IIKO Card **тип программы** должен быть `Бонусная программа`.
[[/info]]
