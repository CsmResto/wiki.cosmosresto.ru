**Cosmos Reservations** - mobile application **for tablets** for working in the reservations system.

iOS link: [App Store](https://apps.apple.com/uz/app/cosmos-reservations/id6780855394)

### Instructions for logging into the application on iOS:

1. Open the application

2. In the **"Connection"** field enter the value that indicates your establishment

    **How to find out:** Take the part of the link where you open Cosmos in the browser. The required part of the link is indicated before csmresto.ru. For example, for https://demo.csmresto.ru/ the value is **demo**. If you are unsure, the value can be clarified from technical support.

3. Click **"Connect"**

4. Enter employee login details

5. Click **"Log in"**

[[info type=custom color=#E06823]]
If you encounter a problem `"Server is temporarily unavailable"` when trying to log in, then most likely the value in the second step was entered incorrectly. For this you need to:

1. Close the application
2. Open the application
3. Click **"Return for connection selection"**
4. In the **"Connection"** field enter the value that indicates your establishment
5. Click **"Connect"**
6. Enter employee login details
7. Click **"Log in"**

If the problem persists, contact technical support, we will help you figure it out
[[/info]]

### Instructions for installing the application on Android:

To use **Cosmos Reservations** on an **Android tablet**, you need to:

1. Open the reservations module in a browser (link format `https://……reserv.csmresto.ru`)

2. Go to page actions - click on three dots

![image1](/ru/images/mobile-apps-install/page-actions.jpg)

[[delimiter rows=1]]

3. Select the action **"Add to home screen"**

![image2](/ru/images/mobile-apps-install/add-reserv-app-to-main-screen.jpg)

[[delimiter rows=1]]

4. In the appearing window select **"Install"**

![image3](/ru/images/mobile-apps-install/install-reserv-app.jpg)

[[delimiter rows=1]]

5. Confirm the installation

![image4](/ru/images/mobile-apps-install/apply-reserv-app.jpg)

[[delimiter rows=1]]

After this, the **Cosmos Reservations** application icon will appear on the home screen - now you can open reservations on the tablet through it.
