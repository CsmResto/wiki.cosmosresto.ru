Если COSMOS не загружается в одном заведении, а в других работает, скорее всего, пропадает связь между сетью заведения и сервером COSMOS. Найти, где именно она пропадает, можно только по замерам, сделанным во время сбоя: когда связь в порядке, замер ничего не покажет.

Замеры выполняются на компьютере, подключенном к сети заведения (Wi-Fi или кабель). VPN должен быть выключен. Подготовку достаточно выполнить один раз, заранее.

[[tab Windows]]

## Подготовка

1. Скачайте архив **WinMTR-v100-static.zip** со страницы [WinMTR на GitHub](https://github.com/White-Tiger/WinMTR/releases/tag/v1.0).

![Архив WinMTR на странице GitHub](/ru/images/connection/connection-check/connection-check-1.png)

[[delimiter rows=1]]

2. Распакуйте архив в удобную папку, например в **Загрузки**. Устанавливать программу не требуется.

![Распакованный архив WinMTR](/ru/images/connection/connection-check/connection-check-2.png)

[[delimiter rows=1]]

3. Запустите файл **WinMTR64.exe**. Если появится окно **Windows защитила ваш компьютер**, нажмите **Подробнее**, затем **Выполнить в любом случае**.

### Пробная проверка подключения

Проверка подключения 5 минут подряд, раз в секунду подключается к серверу COSMOS и показывает, сколько раз связи не было. Пробная проверка нужна, чтобы заранее убедиться, что на этом компьютере проверка работает правильно. Выполните ее, пока COSMOS работает нормально.

1. Нажмите **Пуск**, введите `PowerShell` и откройте **Windows PowerShell**.
2. Вставьте команду и нажмите **Enter**:

```powershell
$ok=0;$fail=0;"Проверка началась, займет 5 минут";for($i=1;$i -le 300;$i++){$c=New-Object Net.Sockets.TcpClient;try{if($c.ConnectAsync('45.89.190.103',443).Wait(3000)){$ok++}else{$fail++;"$(Get-Date -f HH:mm:ss) нет связи"}}catch{$fail++;"$(Get-Date -f HH:mm:ss) нет связи"};$c.Close();if($i % 60 -eq 0){"Проверено $i из 300"};sleep 1};"Готово $(Get-Date -f HH:mm:ss). Успешно: $ok из 300, без связи: $fail"
```

3. Убедитесь, что появилась строка **Проверка началась**.

![Проверка подключения запущена](/ru/images/connection/connection-check/connection-check-6.png)

[[delimiter rows=1]]

Если вместо строки **Проверка началась** появилась строка `>>`, команда не запустилась. Нажмите **Ctrl+C**, скопируйте команду заново и вставьте ее еще раз.

4. Дождитесь строки **Готово** (около 5 минут). Раз в минуту появляется строка **Проверено … из 300**, между ними окно не меняется: проверка идет, нужно просто дождаться ее окончания. Каждая неудачная попытка выводится отдельной строкой со временем, например `15:12:04 нет связи`.

Если в итоговой строке указано **Успешно: 300 из 300**, проверка на этом компьютере работает правильно и ее можно использовать во время сбоя.

![Результат проверки подключения в PowerShell](/ru/images/connection/connection-check/connection-check-5.png)

[[delimiter rows=1]]

[[info type=custom hasIcon icon=warning color=#ff5a3c]]
Если при пробной проверке, когда COSMOS работает нормально, в окне появились красные сообщения об ошибках или строки **нет связи** на каждой попытке, проверка на этом компьютере невозможна. Возможные причины:

- на компьютере установлена Windows 7 без обновлений;
- PowerShell или сетевые проверки ограничены настройками компьютера.

Для замеров используйте другой компьютер.
[[/info]]

## Замеры во время сбоя

Запустите оба замера одновременно, в двух окнах. WinMTR дополнительно показывает путь от компьютера до сервера COSMOS через промежуточные узлы: сеть заведения, провайдера, хостинг. По нему поддержка определяет, на каком участке пропадает связь.

1. Откройте **Windows PowerShell** и запустите команду из раздела **Пробная проверка подключения**.
2. Запустите **WinMTR64.exe**, в поле **Host** введите `45.89.190.103` и нажмите **Start**.

![Окно WinMTR перед запуском замера](/ru/images/connection/connection-check/connection-check-3.png)

[[delimiter rows=1]]

3. Через 5 минут, когда в PowerShell появится строка **Готово**, нажмите **Stop** в WinMTR и сделайте скриншоты обоих окон.

![Результат замера в WinMTR](/ru/images/connection/connection-check/connection-check-4.png)

[[delimiter rows=1]]

## Подготовка

Для установки требуется пароль учетной записи Mac с правами администратора. Подготовка занимает 10-15 минут.

1. Откройте Терминал: **Cmd+Пробел**, введите `Терминал` и нажмите **Enter**.
2. Проверьте, установлен ли Homebrew: введите `brew --version` и нажмите **Enter**. Если появится ответ `command not found`, установите Homebrew командой:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

3. Введите пароль от Mac и нажмите **Enter**. Символы пароля при вводе не отображаются. По окончании установки выполните команды из блока **Next steps** и откройте Терминал заново.
4. Установите программу замера:

```bash
brew install mtr
```

5. Выполните пробный замер (около 10 секунд):

```bash
sudo mtr -n -c 10 --report 45.89.190.103
```

Подготовка завершена, если появилась таблица и ее последняя строка - `45.89.190.103`. Сделайте скриншот таблицы: с ним поддержка сравнит замер во время сбоя.

Если появилось сообщение `not in the sudoers file`, у учетной записи нет прав администратора. Если в первой строке таблицы время больше 40 мс, включен VPN или используется интернет с телефона.

## Замеры во время сбоя

Запустите оба замера одновременно, в двух окнах Терминала. Новое окно открывается сочетанием **Cmd+N**.

1. В первом окне выполните команду и дождитесь окончания замера (около 5 минут):

```bash
sudo mtr -n -c 300 --report 45.89.190.103
```

2. Во втором окне выполните команду:

```bash
sudo mtr --tcp -P 443 -n -c 300 --report 45.89.190.103
```

3. Когда замеры закончатся, сделайте скриншоты обеих таблиц целиком: **Cmd+Shift+3**. Файлы появятся на рабочем столе.

[[/tabs]]

[[info type=custom color=#E06823]]
Пока идут замеры, пожалуйста, не открывайте COSMOS на этом компьютере и не перезагружайте его: работайте с другого устройства.
[[/info]]

## Что отправить в поддержку

1. Время, когда начались проблемы.
2. Скриншот экрана COSMOS во время сбоя: адресная строка и часы должны быть видны.
3. Скриншоты замеров.
