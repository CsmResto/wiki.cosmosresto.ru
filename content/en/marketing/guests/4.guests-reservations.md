The **Reservations** tab contains a list of all reservations associated with the selected guest. Here you can view the reservation history, including active, completed, and cancelled reservations.

![Reservation List](/en/images/guests/reservations-en.png)

[[delimiter rows=1]]


### Reservation Summary

Click **Summary** at the bottom of the window.

![Reservation Summary](/en/images/guests/summary-en.png)

[[delimiter rows=1]]

![Cancelled Reservations Summary](/en/images/guests/summary-cancelled-en.png)

[[delimiter rows=1]]

Use the **Active / Cancelled** switch to view a summary of active and cancelled reservations.

For active reservations, the data is grouped by status; for cancelled reservations, by cancellation reason.

The **Guests** row shows the number of guests in the reservations, while the **Reservations** row shows the number of reservations.

> **Note.** The summary is calculated based on all reservations matching the selected filters.


### Table Management

The table displays information about the selected guest's reservations.

To change the displayed columns, click the table settings button in the upper-right corner.

In the panel that opens, you can:

✔ select the columns to display  
✔ pin the required columns  
✔ restore the default settings using **Reset to Default**

![Column Selection](/en/images/guests/res-column-en.png)

[[delimiter rows=1]]

By default, the following columns are displayed in the table:

- **Status** — the current reservation status: Not Confirmed, Confirmed, Started, Ended, or Cancelled
- **Location** 
- **Start Time** 
- **End Time** 
- **Duration** 
- **Deposit** — the deposit progress
- **Tables**
- **Party Size** 

You can also enable the following columns. Their position in the table follows the column order in the table settings:

- **Reservation** — the unique reservation number
- **Cancellation Reason** 
- **Reservation Note** 
- **Reservation Source** — the source specified when the reservation was created
- **Order** — the order number associated with the reservation. If multiple orders are associated with the reservation, multiple order numbers are displayed
- **Created At** 
- **Created By** — the employee who created the reservation, including their role and grade

> **Note.** Table settings are saved after the page is refreshed and when switching between guest profiles. The settings are reset after you log out.

[[delimiter rows=1]]


### Data Filtering

![Reservations with Filters](/en/images/guests/res-filter-en.png)

[[delimiter rows=1]]

Select the required location from the list to display only reservations associated with that location.

To change the displayed period, select the required date range.

If necessary, click **Filters** to set additional filtering conditions.

After selecting the required values, click **Apply**.

Applied filters are displayed above the table. To remove an individual filter, click **×** next to its name. To reset all filters, click **Clear Filters**.

> **Note.** Selected filter values are saved after the page is refreshed and when switching between guest profiles. The filters are reset after you log out.
