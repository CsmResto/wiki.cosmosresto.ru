You can edit a reservation in several ways: through the sidebar, timeline, floor plan or reservations table.


### Through the Sidebar

1. Click on a reservation on the timeline.
2. In the opened sidebar make changes: guest, table, date and time, number of guests, tags, comment, status.
3. Click `Save` to apply the changes.

[[info type=custom color=#E06823]]
The sidebar also has `Reservation Change Log`.
[[/info]]

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit1.gif) -->

### Using the Timeline

1. Select a reservation on the timeline.
2. Click and hold the reservation again.
3. Drag the reservation to another table or another time.
4. If necessary, add an additional table by selecting it on the timeline.
5. Click `Save` to apply the changes.

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit2.gif) -->

### In the Floor Plan Section

1. Select a reservation in the left sidebar (for convenience you can filter the list by table by selecting it on the floor plan).
2. If necessary, select a table on the floor plan to show only its reservations.
3. In the opened sidebar make changes: guest, table, date and time, number of guests, tags, comment, status.
4. Click `Save` to apply the changes.

[[info type=custom color=#E06823]]
By selecting a table with an `In progress` reservation on the floor plan, you can quickly change the status or edit the reservation time by 15 minutes.
[[/info]]

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit3.gif) -->

### In the Reservations Table

1. Click on a reservation in the list.
2. In the opened sidebar make changes: guest, table, date and time, number of guests, tags, comment, status.
3. Click `Save` to apply the changes.

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit4.gif) -->

## Editing Multi-Reservations

**In a multi-reservation you can:**
- Edit all tables simultaneously.
- Edit individual tables independently. 

To **exclude** a table from editing, click on it.

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit5.gif) -->

### 1. If All Tables Are Selected:
- Increasing or decreasing time on one slot will affect all associated tables.
- The sidebar allows editing of guest, date and time, number of guests, tags, comment, status.
- It is possible to add additional tables by selecting them on the timeline or specifying through the sidebar.


[[info type=custom color=#E06823]]
Editing **time** of a multi-reservation through the sidebar is only available if the start and end times are the same for all tables.
[[/info]]

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit6.gif) -->

### 2. If One Table Is Selected:
- Increase or decrease time on this table, remembering the [limitations](https://wiki.cosmosresto.ru/ru/reservations/reservations/reserv-create/#2-%D0%B2%D1%8B%D0%B1%D0%BE%D1%80-%D1%81%D1%82%D0%BE%D0%BB%D0%B0).
- In the sidebar, start time and duration can be edited for each individual table.

[[info type=custom color=#E06823]]
Even if only one table is selected, changing the guest, number of guests, tags, comment or status changes apply to the entire reservation.
[[/info]]

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit7.gif) -->

## Blocking Reservation Changes

Blocking prohibits changing **guest and table**. Any user can remove the block at any time.

**To block a reservation:**
1. Click `Do not change`.
2. After blocking, hover over the button to see the blocking time and the user who set the block.

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit8.jpg) -->

## Canceling a Reservation

**To cancel a reservation:**

1. Set status to `Cancelled`.
2. Select the reason for cancellation.

After cancellation, the reservation is automatically moved to the `Archive` section.

<!-- ![reserv-edit](/ru/images/reserve/reserv-edit/reserv-edit9.gif) -->
