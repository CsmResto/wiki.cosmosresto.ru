Templates are used for **WhatsApp** mailings. Messages are sent with the text of the selected template - entering custom text is not possible.

After a template is created, Cosmos automatically sends it for approval to Meta via Twilio. Once Meta approves the template, it can be selected for a mailing.

## Template List

![templates](/en/images/mailings/templates-list-en.png)

[[delimiter rows=1]]

To open the list, go to **Marketing → Mailings** and click **Templates**.

Template statuses:

- **On Approval** - the template has been sent for approval, no decision yet
- **Approved** - the template has been approved and can be selected in a mailing
- **Rejected** - the template did not pass approval. It cannot be used in a mailing

The **Search** field searches by template name.

To create a template, click **Create**. For details, see **[Create Template](/en/marketing/mailings/create-template/)**.


## Template Page

![templates](/en/images/mailings/template-page-en.png)

[[delimiter rows=1]]

The template page shows the template name, language, text, buttons, and a message preview.

A template cannot be changed after it is created. To adjust the text or buttons, create a copy: click the duplicate button next to **Delete**. The creation form opens, filled in with the data of the original template. Enter a new name, make the changes, and send the copy for approval.

The copy goes through approval again, even if the original template has already been approved. The original template and the mailings that use it do not change.

A template can be deleted in any status. The exception is a template selected in a mailing or a mailing draft: such a template cannot be deleted.


## Table Settings

To change the displayed columns, click the table settings button in the upper-right corner.

In the panel that opens, you can:

✔ Select the columns to display  
✔ Change the column order - drag a column in the list by the icon to the left of its name  
✔ Pin the required columns - click the pin icon to the right of the column name. Pinned columns move to the beginning of the table  
✔ Restore the default settings using **Reset to Default**

![templates](/en/images/mailings/templates-columns-en.png)

[[delimiter rows=1]]

The template table contains the following columns:

- **Name**
- **Language** - the template language, **RU** or **EN**
- **Template Text**
- **Status**
- **Author**
- **Created At**
- **Last Update**


## Data Filtering

![templates](/en/images/mailings/templates-filters-en.png)

[[delimiter rows=1]]

Click **Filters** to select templates by **Status** and **Language**. You can select several values in each filter.

After selecting the required values, click **Apply**.
