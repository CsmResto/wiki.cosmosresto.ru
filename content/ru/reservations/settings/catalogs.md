В зависимости от процессов заведения в нем используются разные источники бронирований и причины отмены. Для каждой локации настраиваются три списка:

- **Источники бронирования** - доступны при создании и редактировании бронирования.
- **Причины отмены бронирования** - доступны при отмене бронирования, в том числе бронирования в листе ожидания.
- **Причины отклонения заявки** - доступны при отклонении заявки.

В каждом списке выбираются значения, доступные сотрудникам, и одно значение по умолчанию. Оно подставляется автоматически, когда сотрудник создает бронирование, отменяет его или отклоняет заявку.

Чтобы открыть настройку, перейдите в раздел **Бронирование → Настройки**, выберите локацию в поле **Локация** и откройте четвертую вкладку в правом верхнем углу.

![Источники бронирования и причины отмены](/ru/images/reserve/settings-catalogs/settings-catalogs.png)

[[delimiter rows=1]]

Чтобы изменить списки, нажмите **Редактировать** - у названия каждого блока появится значок карандаша. Он открывает окно со всеми возможными значениями: отметьте нужные или нажмите **Выбрать все**, затем **Применить**. Значение по умолчанию снять в этом окне невозможно - сначала выберите по умолчанию другое значение. Чтобы применить изменения, нажмите **Сохранить**.

## Источники бронирования

По умолчанию в локации доступны источники Телефонный звонок, Гость с улицы, Мессенджер и Веб-сайт. Остальные стандартные источники - Email, Социальные сети, Сотрудник, Партнер, Консьерж-сервис, Ивент-агентство - можно включить в окне выбора, которое открывается значком карандаша.

![Выбор источников бронирования](/ru/images/reserve/settings-catalogs/settings-catalogs-sources-edit.png)

[[delimiter rows=1]]

**Источник по умолчанию** - источник, который автоматически подставляется в бронирование при его создании вручную. В бронировании его можно поменять на другой источник из списка.

Источник бронирования из виджета и из Яндекса определяется автоматически и не зависит от этой настройки. В бронировании, созданном из заявки, источник берется из заявки, изменить его невозможно.

### Собственные источники бронирования

Кроме стандартных источников, можно добавить собственный, например название консьерж-сервиса или партнера. Для этого нажмите **Добавить источник**, введите название и сохраните.

![Добавить источник](/ru/images/reserve/settings-catalogs/settings-catalogs-add-source.png)

[[delimiter rows=1]]

У собственного источника вместо крестика значок с тремя точками. Он открывает меню:

- **Убрать из списка** - делает источник недоступным для выбора, как крестик у стандартных источников. Источник не удаляется: чтобы вернуть его, откройте окно выбора значком карандаша и снова отметьте источник.
- **Переименовать**.
- **Деактивировать** - отключает источник навсегда. Бронирования с этим источником сохраняются, но восстановить источник после деактивации невозможно.

![Меню собственного источника](/ru/images/reserve/settings-catalogs/settings-catalogs-source-menu.png)

## Причины отмены бронирования

Причины отмены доступны при отмене бронирования, в том числе бронирования в листе ожидания. Значение из поля **Причина по умолчанию** подставляется автоматически, его можно поменять на другую причину из списка.

Возможные причины разделены на группы:

- **Связанные с гостем**: Отмена гостем, Нет подтверждения, Невозможные изменения, Несогласие с депозитом, Опоздание, Гость не пришел, Некорректные данные.
- **Связанные с заведением**: Нет свободных мест, Заведение закрыто, Технические причины, Несоответствие гостя, Нежелательный гость.
- **Организационные**: Объединение с другой бронью, Перенос в другую локацию, Перенос на другую дату.
- **Административные**: Ошибка, Дубликат брони.

Причины выбираются в окне, которое открывается значком карандаша у блока **Причины отмены бронирования**.

![Карандаш у причин отмены бронирования](/ru/images/reserve/settings-catalogs/settings-catalogs-cancel-pencil.png)

## Причины отклонения заявки

Причины отклонения доступны при отклонении заявки. Они выбираются из тех же групп, что и причины отмены, но настраиваются отдельно, со своим значением в поле **Причина по умолчанию**.

Причины выбираются в окне, которое открывается значком карандаша у блока **Причины отклонения заявки**.

## Значения, убранные из списка

Если значение убрать из списка или деактивировать, уже сохраненные бронирования не меняются:

- В бронированиях, где оно было выбрано, значение продолжает отображаться.
- В статистике данные по этому значению сохраняются.

Выбрать такое значение в новом или существующем бронировании невозможно. Если в бронировании заменить его другим и сохранить изменения, вернуть прежнее значение уже невозможно.

В фильтрах списков бронирований и заявок предлагаются только значения, включенные в настройке.
