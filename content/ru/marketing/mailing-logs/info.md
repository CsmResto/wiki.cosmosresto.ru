В **Журнале рассылок** отображается информация об отправке сообщений гостям. Каждая строка журнала соответствует отдельной отправке.

![список отправок](/ru/images/mailing-logs/logs.png)

[[delimiter rows=1]]

Для просмотра отправок за определенный период выберите нужный диапазон дат.

Нажмите на строку в таблице, чтобы перейти к настройкам соответствующей рассылки.

## Фильтры

Чтобы отобрать отправки по заданным параметрам, нажмите **Фильтры**.


![filters](/ru/images/mailing-logs/filters.png)

[[delimiter rows=1]]

Выберите необходимые значения и нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.

> **Примечание.** Выбранные значения фильтров сохраняются после обновления страницы. После выхода из системы фильтры сбрасываются.

## Настройки таблицы

Для изменения набора отображаемых столбцов нажмите кнопку настройки таблицы в правом верхнем углу.

![column](/ru/images/mailing-logs/column.png)

[[delimiter rows=1]]

В открывшейся панели можно:

✔ Выбрать отображаемые столбцы  
✔ Закрепить нужные столбцы  
✔ Вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

> **Примечание.** Настройки таблицы сохраняются после обновления страницы. После выхода из системы настройки сбрасываются.


## Экспорт


Чтобы выгрузить данные из журнала, нажмите кнопку экспорта в правом верхнем углу таблицы.

В экспорт попадают данные с учетом выбранного периода и примененных фильтров. Экспортируются только столбцы, включенные в настройках таблицы.

Закрепленные столбцы располагаются в начале таблицы и сохраняют это положение в экспортированном файле.

![export](/ru/images/mailing-logs/export.png)
