Виджет бронирования — это форма на сайте заведения, через которую гость сам оставляет заявку на бронирование. Заявки из виджета поступают в систему, их обработка описана в статье **[Заявки на бронирование](https://wiki.cosmosresto.ru/ru/reservations/reservations/requests/)**.

Для работы с виджетами откройте раздел **Бронирование → Виджеты**. Здесь можно создать виджет, настроить его внешний вид и поля формы, проверить результат в предварительном просмотре и получить код для размещения на сайте.

[[info type=custom color=#E06823]]
Виджет можно подготовить и разместить на сайте заранее. Заявки в локацию начинают поступать только после того, как для нее включен прием онлайн-бронирований из виджета.
[[/info]]





## Список виджетов

В таблице отображаются все созданные виджеты. По умолчанию список отсортирован по дате создания: новые виджеты вверху.

![Виджеты](/ru/images/reserve/widgets/widget-list.png)

[[delimiter rows=1]]

- **Гео** — выбор локаций, виджеты которых отображаются в списке.
- **Поиск** — поиск виджета по названию.
- **Фильтры** — отбор виджетов по условиям.
- **Создать** — создание нового виджета.

Чтобы открыть виджет для просмотра и изменения, нажмите на его строку.

## Настройки таблицы

Для изменения набора отображаемых колонок нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ Выбрать отображаемые колонки  
✔ Изменить порядок колонок — перетащите колонку в списке за значок слева от ее названия  
✔ Закрепить нужные колонки — нажмите на значок булавки справа от названия колонки. Закрепленные колонки перемещаются в начало таблицы  
✔ Вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

![Настройки таблицы](/ru/images/reserve/widgets/widget-columns.png)

[[delimiter rows=1]]

По умолчанию в таблице отображаются следующие колонки:

- **Дата создания**
- **Название**
- **Локации** 
- **Автор** 
- **Последнее обновление** 
- **Описание**

## Фильтры

Примененные фильтры отображаются над таблицей рядом с кнопкой **Фильтры**.

У каждого поля в окне фильтров есть значок булавки — с его помощью можно закрепить фильтр.

Кнопка **Очистить фильтры** удаляет незакрепленные фильтры и сбрасывает значения в закрепленных фильтрах.

![Фильтры](/ru/images/reserve/widgets/widget-filters.png)
