Manual Tags allow you to manually mark guests and store information that should be taken into account when providing service. For example, they can be used to identify VIP guests, dietary restrictions, preferences, or special service requirements.

Manual Tags are used in several sections of the system:

✔ **Reservations** — tags can be displayed in the guest profile, on the reservation timeline, and on the floor plan tables, depending on the group settings. If editing is enabled, tags can be assigned and removed directly from a reservation

✔ **Guests** — tags are displayed in the guest list and guest profile, where they can be assigned and removed

✔ **Waiter App** — tags can be viewed and assigned to guests if this is allowed in the group settings

✔ **Guest Segments** — tags are used as one of the filters when creating segments

## Manual Tag Group List

The Manual Tag Group List displays the created groups and their main parameters.

To find a group, use the search bar at the top of the page. The search is performed by group name.

## Table Settings

![Column Wizard](/en/images/manual-tags/tags-column-en.png)

[[delimiter rows=1]]

To change the displayed columns, click the table settings button in the upper-right corner.

In the panel that opens, you can:

✔ select the columns to display  
✔ pin the required columns  
✔ restore the default settings using **Reset to Default**

> **Note.** Table settings are saved after the page is refreshed. The settings are reset after you log out.

## Data Filtering

![Filter](/en/images/manual-tags/tags-filter-en.png)

[[delimiter rows=1]]

To quickly find the required group, use the search bar and filters above the table.

Filtering is available by the following parameters:

✔ Author  
✔ Created At  
✔ Available in Waiter App  
✔ Reservations Display  
✔ Last Update  
✔ Editable in Reservations

> **Note.** Filter settings are saved after the page is refreshed. The settings are reset after you log out.
