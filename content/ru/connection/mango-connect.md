**Mango Office** - виртуальная АТС. После подключения Cosmos получает события о входящих и исходящих звонках заведений.

Настройка выполняется в личном кабинете Mango Office. Если сеть работает по франшизе, каждый франчайзи настраивает подключение в своём кабинете.

**Перед началом запросите у поддержки Cosmos адрес внешней системы для подключения.**

## Настройка API Коннектора

**1.** Перейдите в раздел **Виртуальная АТС → Интеграции → API Коннектор**.

**2.** Нажмите **Добавить систему**. Действующее подключение к текущей системе бронирования отключать не нужно.

[[info type=custom color=#E06823]]
Если кнопки **Добавить систему** нет, обратитесь в Mango Office для увеличения лимита внешних систем.
[[/info]]

**3.** Для нового подключения укажите название **COSMOS**, а в поле **Адрес внешней системы** вставьте адрес, полученный от поддержки Cosmos.

**4.** Проверьте настройки событий:
- параметр **Не отправлять уведомления о промежуточном состоянии вызова** должен быть выключен;
- номера подключаемых заведений не должны быть исключены из отправки событий.

**5.** Если для API включено ограничение доступа по IP-адресам, сообщите об этом в поддержку Cosmos - мы пришлём адреса, которые нужно разрешить.

## Маршрутизация звонков

Проверьте настройки в каждом подключаемом заведении:

- Входящие звонки на внешний номер заведения должны попадать в группу этого заведения, а не напрямую на сотрудника. Звонки мимо группы невозможно привязать к заведению.
- У каждой группы должен быть внутренний номер, состоящий только из цифр.
- Сотрудники, которые принимают и совершают звонки от имени заведения, должны входить в группу этого заведения и иметь свой внутренний номер. По нему к заведению привязываются их исходящие звонки.

## Данные для поддержки Cosmos

Передайте в поддержку Cosmos:

- **Уникальный код вашей АТС** и **Ключ для создания подписи** из блока **Данные вашей АТС** - через защищённый канал;
- список: заведение → внешний номер → название и внутренний номер группы Mango.

[[info type=custom color=#E06823]]
Новые ключи генерировать не нужно: это затронет действующую интеграцию.

У каждой виртуальной АТС свои учётные данные. Использовать ключи одной АТС для подключения другой невозможно.
[[/info]]

После этого дождитесь завершения настройки интеграции со стороны Cosmos.
