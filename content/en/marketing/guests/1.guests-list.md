The **Guests** page displays a list of guests and basic information about each of them.

To work with the list, you can select a location or location group, use search and filters, and configure the table columns.

![Guest List](/en/images/guests/guests-list-en.png)

[[delimiter rows=1]]


## Location Selection

In the location selector, you can select an individual **location**, a **location group**, or **All**.

![Location and Filter](/en/images/guests/guests-location-en.png)

[[delimiter rows=1]]

Selecting a location or group does not change the list of guests in the table. It determines which locations are used to display statistics for each guest.

If a guest has activity at the selected location, the table displays their metrics for that location, such as the last visit and total amount spent. If there was no activity at the selected location, dashes are displayed in the corresponding columns.

The selected location is also taken into account when filtering the list. For example, if you select a specific location and set a filter for the amount spent, the table will show guests whose spending at that location meets the specified condition.

For more information about location groups, see **[Location Groups](/en/marketing/location-groups/)**.


## Search

To find a guest, use the search bar above the table.

You can search by first name, last name, primary phone number, email, or loyalty card number.


## Table Settings

To change the displayed columns, click the table settings button in the upper-right corner.

![Column Wizard](/en/images/guests/guests-column-en.png)

[[delimiter rows=1]]

In the panel that opens, you can:

✔ select the columns to display  
✔ pin the required columns  
✔ restore the default settings using **Reset to Default**

> **Note.** Table settings are saved after the page is refreshed. The settings are reset after you log out.


## Filters

If necessary, click **Filters** to set additional filtering conditions.

![Guest Filters](/en/images/guests/guests-filters-en.png)

[[delimiter rows=1]]

After selecting the required values, click **Apply**.

Applied filters are displayed above the table. To remove an individual filter, click **×** next to its name. To reset all filters, click **Clear Filters**.

> **Note.** Filter settings are saved after the page is refreshed. The settings are reset after you log out.
