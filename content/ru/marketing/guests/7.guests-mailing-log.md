Вкладка **Журнал рассылок** содержит список всех рассылок, отправленных выбранному гостю из модуля **[Рассылки](/ru/marketing/mailings/)**. Вкладка помогает быстро найти нужную рассылку, узнать, когда и по какому каналу было отправлено сообщение, и проверить статус доставки.

![журнал рассылок гостя](/ru/images/guests/mailing-log.png)

[[delimiter rows=1]]

Каждая строка соответствует отдельной отправке. Те же отправки по всем гостям отображаются в общем **[Журнале рассылок](/ru/marketing/mailing-logs/info/)**.

Даты в таблице отображаются в часовом поясе пользователя.


### Информация об отправке

Нажмите на строку в таблице, чтобы открыть сайдбар **Информация о логе рассылки** с подробными данными об отправке: даты, канал связи, тип рассылки, статус, стоимость, получатель, отправитель и полный текст сообщения.

![сайдбар лога рассылки](/ru/images/guests/mailing-log-sidebar.png)

[[delimiter rows=1]]

Чтобы перейти к настройкам рассылки, нажмите на строку правой кнопкой мыши и выберите **Перейти к рассылке**. Команда **Просмотр лога рассылки** в этом же меню открывает сайдбар.

![контекстное меню](/ru/images/guests/mailing-log-menu.png)

[[delimiter rows=1]]

Перейти к рассылке можно и из открытого сайдбара - нажмите на значок ↗ рядом с названием рассылки.


### Фильтрация данных

Для изменения периода выберите нужный диапазон дат в поле периода в верхней части страницы. Период фильтрует записи по плановой дате отправки.

Для дополнительных условий нажмите **Фильтры**.

![фильтры журнала рассылок](/ru/images/guests/mailing-log-filter.png)

[[delimiter rows=1]]

В панели можно отфильтровать записи по следующим параметрам:

✔ канал связи  
✔ название  
✔ отправитель  
✔ статус  
✔ тип рассылки

После выбора необходимых значений нажмите **Применить**.

Примененные фильтры отображаются над таблицей. Для удаления отдельного фильтра нажмите **×** рядом с его названием. Чтобы сбросить все фильтры, нажмите **Очистить фильтры**.

> **Примечание.** Выбранные фильтры сохраняются при переходе между профилями гостей. После выхода из системы фильтры сбрасываются.


### Настройки таблицы

Для изменения набора отображаемых колонок нажмите кнопку настройки таблицы в правом верхнем углу.

В открывшейся панели можно:

✔ Выбрать отображаемые колонки  
✔ Изменить порядок колонок - перетащите колонку в списке за значок слева от ее названия  
✔ Закрепить нужные колонки - нажмите на значок булавки справа от названия колонки. Закрепленные колонки перемещаются в начало таблицы  
✔ Вернуть настройки по умолчанию с помощью команды **Сбросить к начальным значениям**

![настройки колонок](/ru/images/guests/mailing-log-columns.png)

[[delimiter rows=1]]

По умолчанию в таблице отображаются следующие колонки:

- **Плановая дата** - дата и время, на которые запланирована отправка. По умолчанию таблица отсортирована по этой колонке, сначала новые
- **Дата отправки** - дата и время фактической отправки сообщения
- **Название**
- **Канал связи**
- **Тип рассылки**
- **Статус отправки**
- **Стоимость** - стоимость отправки SMS
- **Контент**
- **Вложения**
- **Отправитель**
