**CosmosResto Team** - мобильное приложения для входа на смены, просмотра зарплат, квестов и модификаторов.

Ссылка на iOS: [App Store](https://apps.apple.com/uz/app/cosmos-team/id6780405989)

Ссылка на Android: [Google Play](https://play.google.com/store/apps/details?id=ru.cosmosresto.team)

### Инструкция для входа:

1. Открыть приложение

2. В поле **Подключиться к** введите название вашей компании в CosmosResto маленькими буквами, например **my-restaurant**. Это значение одно для всех ресторанов компании.

    **Как узнать:** откройте CosmosResto в браузере на компьютере и посмотрите на адрес сайта. Нужна часть до **.csmresto.ru**. Например, если адрес **my-restaurant.csmresto.ru**, введите **my-restaurant**. Если сомневаетесь, напишите в техподдержку - мы подскажем.

![Поле подключения в приложении Team](/ru/images/mobile-apps-install/team-connection.png "230")

[[delimiter rows=1]]

3. Кликнуть **"Подключиться"**

4. Ввести данные сотрудника для входа

5. Кликнуть **"Войти"**

[[info type=custom color=#E06823]]
Если при попытке войти возникает проблема `"Сервер временно недоступен"`, то скорее всего значение на втором шаге было введено неверно. Для этого нужно:

1. Кликнуть на текст **"Вернуться к выбору приложения"**
2. В поле **Подключиться к** заново введите название компании маленькими буквами, как в шаге 2.
3. Кликнуть **"Подключиться"**
4. Ввести данные сотрудника для входа
5. Кликнуть **"Войти"**

Если проблема повторяется, напишите в техническую поддержку, мы поможем разобраться
[[/info]]
