**Cosmos Reservations** - мобильное приложение **для планшетов и телефонов** для работы в системе бронирований.

Ссылка на iOS: [App Store](https://apps.apple.com/uz/app/cosmos-reservations/id6780855394)

Ссылка на Android: [Google Play](https://play.google.com/store/apps/details?id=ru.cosmosresto.reservations)

### Инструкция для входа в приложение:

1. Открыть приложение

2. В поле **"Connection"** ввести значение, обозначающее принадлежность к вашему заведению

    **Как узнать:** Возьмите часть ссылки, по которой открываете Cosmos в браузере. Нужная часть ссылки указана до csmresto.ru. Например, для https://demo.csmresto.ru/ значение — **demo**. Если сомневаетесь, значение можно уточнить у техподдержки.

3. Кликнуть **"Connect"**

4. Ввести электронную почту и пароль сотрудника

5. Кликнуть **"Войти"**

[[info type=custom color=#E06823]]
В приложение входят только по электронной почте и паролю, входа по ПИН-коду в нем нет. Чтобы сотрудник мог войти, в настройках его роли должен быть включен переключатель **Разрешить вход без ПИН-кода**.
[[/info]]

[[info type=custom color=#E06823]]
Если при попытке войти возникает проблема `"Сервер временно недоступен"`, то скорее всего значение на втором шаге было введено неверно. Для этого нужно:

1. Закрыть приложение
2. Открыть приложение
3. Кликнуть **"Вернуться к подключению"**
4. В поле **"Connection"** ввести значение, обозначающее принадлежность к вашему заведению
5. Кликнуть **"Connect"**
6. Ввести данные сотрудника для входа
7. Кликнуть **"Войти"**

Если проблема повторяется, напишите в техническую поддержку, мы поможем разобраться
[[/info]]
