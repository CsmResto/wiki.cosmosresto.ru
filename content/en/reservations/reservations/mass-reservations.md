**Multi-table reservation** is a reservation for 2 or more tables. This type of reservation has its own peculiarities and limitations, which we will discuss below.

[[info type=custom color=#E06823]]
When creating a reservation for multiple tables, **there should be no time gaps between all tables.**

**The system will show itself if there is a time gap between tables in one reservation.**

<!-- ![reserv-multitable](/ru/images/reserve/multitable.jpg) -->


## Selecting Multiple Tables via Sidebar

<!-- ![reserv-multitable](/ru/images/reserve/reserv-table-multiselect.jpg) -->

[[delimiter rows=1]]

**1.** Open the table list.

**2.** At the bottom enable the option `Select multiple tables`.

**3.** You can also find a suitable table by name, filter tables by needed criteria and sort the list.

**4.** Select the required tables, then click `Apply`.

## Selecting Multiple Tables via Timeline

<!-- ![reserv-multitable](/ru/images/reserve/timeline-view/timeline-view-multi.gif) -->

**1.** Open the section `Timeline`.

**2.** By holding and dragging to the side, select the tables you are interested in.

**3.** In the opened sidebar, fill in the remaining reservation data. All fields for creating a reservation are described in more detail in [this article](https://wiki.cosmosresto.ru/en/reservations/reservations/reserv-create/).
