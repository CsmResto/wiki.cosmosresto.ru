Гастропара связывает блюда из заказа с блюдами, которые стоит предложить гостю дополнительно: например, к бургеру - картофель фри, к вину - сыр. Когда официант добавляет в заказ блюдо из гастропары, приложение показывает под ним предложения.

Чтобы открыть гастропары, перейдите в раздел **Официант → Гастропары**.

## Список гастропар

Гастропары отображаются карточками. В карточке указаны название, локация, блюда из блока **Если гость выбирает** и предложения из блока **Тогда предложите**. Если блюд больше, чем помещается в карточке, рядом отображается счетчик, например **+2**.

Список можно отфильтровать по локациям в поле **Гео** и найти гастропару по названию через **Поиск**.

## Создание гастропары

Нажмите **Создать** и заполните поля. Справа отображается предпросмотр: как предложения будут выглядеть в заказе в приложении.

![Создание гастропары](/ru/images/waiter/settings/pairings-create.png)

[[delimiter rows=1]]

- **Локация** - локация, для которой работает гастропара. Для каждой гастропары выбирается только одна локация.
- **Название** - название гастропары для списка, до 50 символов.
- **Если гость заказывает** - **Родительское блюдо**, при заказе которого приложение предлагает дополнительные блюда. Чтобы гастропара срабатывала на сочетание блюд, нажмите **Добавить «Вместе»** и выберите еще одно блюдо. Например, если гость заказал бургер вместе с колой, приложение предложит пирожок.
- **Тогда предложите** - группы **Дополнительные блюда**, которые приложение предложит официанту. Чтобы добавить группу, нажмите **Добавить группу блюд**, всего можно добавить до 5 групп. Порядок групп меняется перетаскиванием, удалить группу можно значком корзины.

Чтобы сохранить гастропару, нажмите **Создать**.

## Действия с гастропарой

Действия с гастропарой открываются по кнопке **⋮** в правом верхнем углу карточки. Если меню нескольких локаций совпадает, гастропару не нужно собирать заново - ее можно продублировать и выбрать в копии другую локацию. При дублировании открывается форма новой гастропары с заполненными полями, к названию добавляется **[Копия]**. Продублировать гастропару можно и из ее карточки.

![Меню гастропары](/ru/images/waiter/settings/pairings-menu.png)

[[delimiter rows=1]]

[[info type=custom color=#E06823]]
Локацию можно сменить и в новой, и в уже созданной гастропаре. При смене локации из выбора убираются блюда, которых нет в меню новой локации.
