The events widget is placed on the venue's website. In it, the guest sees the event calendar, opens an event and buys tickets.

Widgets are in **Events → Widgets**.

![Widget list](/en/images/events/widgets-list-en.png)

[[delimiter rows=1]]

- **Geo** - the locations whose widgets are shown in the list.
- **Search** - search by widget name.
- **Filters** - filtering by author, creation date, who changed the widget and last update date.
- **Create** - creates a new widget.

To open a widget, click its row.

## How Events Get into the Widget

You do not need to add events to the widget. The widget automatically shows all published events of its locations. If several locations are linked to the widget, it shows the events of all of them.

Everything the guest sees comes from the event: name, description, image, date, ticket levels and prices. The image is uploaded on the event page in the **Design** block.

Drafts and unpublished events are not shown in the widget. If an event has ended or its tickets are sold out, the widget keeps the event page without the purchase form.

## Widget on the Website

The widget has two tabs:

- **Calendar** - events by day of the month. If several events take place on one day, the cell shows how many there are.
- **Events** - cards of the month's events: image, date and time, name, number of available seats, description and ticket price.

## Creating a Widget

After saving, the widget page shows the **Embed Code** button in the top right corner, the **Delete** button and the duplicate button next to it.

![Widget page](/en/images/events/widget-form-en.png)

[[delimiter rows=1]]

- **Name** - the guest does not see it. The name helps tell widgets apart in the list, for example by the website the widget is on.
- **Locations** - the locations whose events the widget shows.
- **Description** - a note for staff, the guest does not see it. This field is optional.
- **Background**, **Accent**, **Text**, **Fields** - widget colors. **Fields** is the background color of input fields.

The **Preview** on the right shows a test event. It is there to check the colors, your events are not in it. The switches above it show the mobile and desktop versions.

The purchase form fields are the same in all widgets and cannot be changed. The link to the personal data processing agreement in the form comes from the event.

## Placing the Widget on Your Website

The **Embed Code** button opens the **How to embed code** window with ready-made code and setup steps. The widget can be embedded as a button that opens it in a separate window, or as a block right on the page. Both options can be used on the same website. It is enough to pass the window contents to your website developer.

![How to embed code](/en/images/events/widget-embed-code-en.png)

[[delimiter rows=1]]

If an ad leads to a page of your website without the widget, a separate short code from the window is added to that page. It keeps the campaign tags so they are not lost when the guest goes to the page with the widget.

If you change the widget, the code on your website may become outdated: update it on all websites where the widget is placed. A deleted widget stops selling tickets, and its code should be removed from the website.
