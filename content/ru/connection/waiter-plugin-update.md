## Первая установка плагина:

1. Запустить установщик Cosmos Waiter.
2. Подствердить корневую папку (папка, в которой лежит файл запуска кассы) и папку конфигов. Папки будут рекомендованы автоматически.
3. После установки касса перезапустится самостоятельно (если этого не произошло, нужно перезапустить её вручную).
4. Проверить успешную остановку в сообщениях при запуске кассы. Должны отобразиться два сообщения "Cosmos Waiter загружен\запущен".
5. Во открывшемся окне ввести токен доступа, предоставленный поддержкой Cosmos.

## Обновление плагина:

1. Зайти в дополнения IIKO.
2. Выбрать **Cosmos Waiter настройка**.
3. Если обновление необходимо, будет отображено сообщение `Доступна новая версия` и активна конопка `Обновить`.
4. Нажать `Обновить`. Запустится установщик.
5. Нажать `Установить`.
6. Принять закрытие IIKO Front. Касса закроется.
7. Через некоторое время (меньше минуты) откроется установщик с сообщением `Обновление установлено`.
8. Нажать `Закрыть`.
9. Запустить кассу IIKO Front самостоятельно.
10. Проверить успешное обновление в сообщениях при запуске кассы. Должны отобразиться два сообщения "Cosmos Waiter загружен\запущен".

## Возможные ошибки:

### Недостаточно прав для доступа к папке:

Есть два варианта решения проблемы

1. Запустить кассу от администратора и идти по шагам обновления выше.
2. Запустить файл установщика Cosmos Waiter с правами администратора.


### Сетевой порт занят:

Завершить процесс alloy-windows-amd64.exe в диспечере.

### Исполняемый файл IIKO Front не найден: 

1. Закрыть кассу.
2. Зафиксировать название `.exe` файла запуска кассы в корневой папке.
3. Поменять название файла запуска кассы в корневой папке на название из списка ("iikoFront.Net.exe", "Resto.Front.Api.Host.exe", "Resto.Front.Main.exe").
4. Снова запустить установщик.
5. Обновить Waiter.
6. Вернуть название запуска кассы в корневой папке.
7. Перезапустить кассу.
8. Проверить успешность установки. Должны отобразиться два сообщения "Cosmos Waiter загружен\запущен".
